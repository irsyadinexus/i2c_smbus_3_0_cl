7. Architecture Summary

7.1 Master Architecture

  • SCL Generation: 3-phase stretch-aware divider (SCL_HIGH → SCL_LOW → SCL_WAIT)
  • Asymmetric timing: Separate LOW_CNT and HIGH_CNT for t_LOW spec compliance
  • Time base: 50 MHz system clock → 1,750,000 cycles = 35 ms timeout
  • PEC: CRC-8 computed in parallel with transaction, appended after last data byte
  • SDA hold: Registered pipeline delays SDA output by t_HD;DAT after SCL falling edge

7.2 Slave Architecture

  • Address matching: Combinational compare on captured shift_reg[7:1]
  • START/STOP detection: Edge-based with synchronizer (2-stage flip-flop)
  • START gating: Only fires in S_IDLE or data-phase states (avoids false detect)
  • STOP handling: All 6 FSM states now transition to S_IDLE on STOP
  • Clock stretch: Active-low SCL output (open-drain) for flow control
  • ARP: UDID byte counter uses pre-NBA bit_pos check (bit_pos == 7)

8. Conclusion

The I2C controller with SMBus 3.0 features has been verified across 5 testbenches, 58 test cases, and 2 clock frequencies with zero failures. All features — including PEC CRC-8, SMBALERT#/ARA, ARP (all commands and 16-byte UDID), clock stretching, and SMBus 35ms timeout with STOP-only recovery — pass at both 100 kHz and 400 kHz.

Six RTL bugs were identified and fixed during verification, including a critical FSM robustness improvement (stop_detected handled in all slave states) that enables proper bus recovery after forced SCL-low timeout conditions.

The design is synthesis-ready — all RTL uses standard SystemVerilog constructs (always_ff/always_comb, synchronous resets) suitable for FPGA or ASIC implementation.
